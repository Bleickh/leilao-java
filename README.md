 Sistema de Leilões

Sistema de Leilões desenvolvido em Java utilizando o NetBeans, com integração ao banco de dados MySQL.  
O sistema permite o cadastro e a consulta de produtos de forma simples e funcional.

---

 Funcionalidades

- ✅ Cadastro de produtos  
- ✅ Listagem de produtos cadastrados  
- ✅ Integração com banco de dados MySQL  
- ✅ Interface gráfica com Java Swing  
- ✅ Organização em camadas (DAO, View, Model)

---

 Tecnologias Utilizadas

- Java  
- MySQL  
- NetBeans  
- Git e GitHub  

---

  Banco de Dados

Banco utilizado: `uc11`

### Tabela: `produtos`

| Campo   | Tipo        | Descrição              |
|--------|------------|----------------------|
| id     | INT (PK)   | Identificador do produto |
| nome   | VARCHAR    | Nome do produto       |
| valor  | INT        | Valor do produto      |
| status | VARCHAR    | Status do produto     |
